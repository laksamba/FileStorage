🚀 Overview

This project is a decentralized file storage DApp that allows users to upload files to IPFS (via Pinata) and store their hashes on the Ethereum blockchain. It utilizes Hardhat for smart contract development and React for the frontend.

## 🏗 Tech Stack

Frontend: React, Ethers.js, Tailwind CSS

Backend: Solidity Smart Contracts (Hardhat)

Storage: IPFS (Pinata)

Blockchain Network: Sepolia Testnet

## 📜 Features

✅ Upload files to IPFS using Pinata
✅ Store and retrieve file hashes on the Ethereum blockchain
✅ Connect and interact with MetaMask
✅ Display stored file hashes in the frontend
✅ Fully decentralized file management
